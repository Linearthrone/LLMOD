# Neural Signal Flow Visualization

An abstract p5.js sketch representing neural signal flow between digital and somatic feedback loops.

## Description

This interactive visualization demonstrates the flow of neural signals between digital and somatic feedback systems using particle systems, Perlin noise for fluid motion, and color gradients. The aesthetic is based on Deep Burgundy (#8B0000) and Electric Gold (#FFD700) to represent the neural pathways.

## Features

- Particle systems representing neural signals
- Perlin noise for fluid, organic motion
- Interactive elements:
  - Click to add neural nodes
  - Drag to create particle flow
- Color gradients between Deep Burgundy and Electric Gold
- Additive blending for luminous effects
- Connection points that pulse and influence particle flow

## How to Run

1. Open `index.html` in a web browser
2. Interact with the visualization:
   - Click anywhere to add neural nodes
   - Click and drag to create particle flow

## Code Structure

- `sketch.js`: Main p5.js code implementing the visualization
- `index.html`: HTML file to host the sketch

## Libraries Used

- [p5.js](https://p5js.org/): JavaScript library for creative coding

## Color Palette

- Deep Burgundy: #8B0000
- Electric Gold: #FFD700
- Background: Dark purple gradient
