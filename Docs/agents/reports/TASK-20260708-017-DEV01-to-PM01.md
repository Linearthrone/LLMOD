## Technical Decisions

- **One resolver per language, identical order.** PowerShell and C# can't share code, so there are
  two implementations (`HermesShared.ps1`, `HermesPaths.cs`) with the SAME documented 3-step order,
  each cross-referencing the other in comments. The old bug was that `setup-persona-mcp.ps1`
  hardcoded `%USERPROFILE%\.hermes` while the gateway/other script could resolve elsewhere — now all
  three agree.
- **Persistence reuses `UserSettingsStore`** (the existing JSON store used by the autonomy drawer),
  so `AllowComputerControl` survives rebuilds/`start.bat` exactly like other user-edited settings.
  The monitor service is the runtime source of truth (bound to the checkbox) and writes through to
  the shared singleton `AppConfig`, so `HermesAIService` and the SMS/remote tool-guide path both see
  the live value.
- **Control is independent of sharing.** Sharing = she can see (screenshot attached); control = she
  may act (`computer_use`). Default `AllowComputerControl=false` for safety.
