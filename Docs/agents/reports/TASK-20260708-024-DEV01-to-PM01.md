## Technical Decisions

### tool_choice investigation

Inspected Hermes gateway source at `%LOCALAPPDATA%\hermes\hermes-agent\gateway\platforms\api_server.py`.
The `/v1/chat/completions` handler reads `messages`, `model`, and `stream` only — it does **not** forward
`tool_choice` (or client `tools`) into `_run_agent`. Hermes manages its own tool loop internally.

**Action taken:** House Victoria still sends:

```json
"tool_choice": {"type":"function","function":{"name":"mcp_computer_use_computer"}}
```

for the gated case (forward-compatible if gateway adds support). **Primary fix is mandatory user-payload
instruction**, not tool_choice.

### User payload shape (control ON + screenshot-shaped message)

Order in user `content`:

1. `[MANDATORY FIRST ACTION — …]` (prepended)
2. User message + `[You MUST call mcp_computer_use_computer …]` inline guidance
3. `[DESKTOP SCREENSHOT ROUTING: …]` (appended)

Unchanged when control OFF or message is not screenshot-shaped.
