## What changed (behavior)

### Before (DEV-017, control ON)

Hermes `/v1/chat/completions` messages array looked like:

```
[0] role=system   content=<persona SystemPrompt only>
[1..N] role=user/assistant  content=<history>
[N+1] role=user   content=<user message>

  + inline suffix only:
    "[You MAY use the computer_use tool (screenshot/click/type/scroll)…]"
```

No tool guide naming `computer_use (action=screenshot)` or forbidding `browser_vision`. Model picked
`browser_vision` on natural screenshot wording (QA-021).

### After (this task, control ON)

Same request with screenshot-shaped message:

```
[0] role=system   content=<persona SystemPrompt>
[1] role=system   content=<full BuildHermesToolGuide with DESKTOP CONTROL section>
[2..N] role=user/assistant  content=<history>
[N+1] role=user   content=<user message>

  + inline suffix:
    "[You MAY use the computer_use tool…]"

  + when message matches screenshot/desktop/active window/my screen:
    "[DESKTOP SCREENSHOT ROUTING: … Call computer_use (mcp_computer_use_computer) with action=screenshot …
     Do NOT use browser_vision, browser, or terminal …]"
```

Multimodal path (screen sharing ON + control ON): same system guide injection; user content is still
the text+image array with the steering block appended to the text part.

### Control OFF (unchanged safe behavior)

- No tool-guide system message added.
- No desktop-screenshot steering appended.
- Share-screen path still forbids `computer_use` when control OFF (DEV-017 behavior preserved).
