1. **Model tool selection:** `qwen3-coder:480b-cloud` still prefers Hermes built-ins (`terminal`, `vision_analyze`, skill/MCP discovery) over `mcp_computer_use_computer` despite explicit steering text.

4. **Test path gotcha:** Remote API with **non-primary contact** bypasses Hermes entirely — must use Victoria (primary) for criterion 3.
