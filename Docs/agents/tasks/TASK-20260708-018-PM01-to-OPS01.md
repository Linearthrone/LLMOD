# Task · Validate the live Hermes + computer-use runtime on this machine

## Background

Victoria's computer-use (mouse/keyboard/screen) runs through external **Hermes Agent** (`:8642`)
which spawns the **`computer-use-mcp`** npm server via `npx`. DEV ticket `017` fixes the
code/config-authoring side; this ticket confirms the **actual machine state** so we know whether the
capability can run at all today. This is validation + environment prep only — no product code
changes.

## Change description

No files changed by OPS. This is a runtime audit of Hermes install, config, Node/npx, gateway, and
the `computer_use` MCP registration, capturing real command output as evidence.

## Steps (capture full output for each)

1. **Hermes install & config path**
   - `hermes --version`
   - `hermes config path`  → record the resolved path (expect `%LOCALAPPDATA%\hermes\config.yaml`
     or `%USERPROFILE%\.hermes\config.yaml`).
   - Dump the resolved `config.yaml`; confirm `mcp_servers.computer_use` exists with
     `enabled: true` and `command: npx`, `args: ["-y","computer-use-mcp"]`.
   - Confirm `mcp_servers.house_victoria` also present.
2. **Config/env split check** (the known footgun)
   - Check BOTH `%LOCALAPPDATA%\hermes\` and `%USERPROFILE%\.hermes\` for `config.yaml` and `.env`.
   - Report which dir actually holds the config the gateway uses and where the API key `.env` lives
     (gateway currently reads `%USERPROFILE%\.hermes\.env`). Flag any mismatch.
3. **Node / npx**
   - `node --version` (need 18+), `npx --version`.
   - `npx -y computer-use-mcp --help` (or equivalent) to confirm the package resolves and launches.
4. **Gateway**
   - Confirm `PrimaryLLM=hermes` in `HouseVictoria.App\App.config` and `primary-llm.txt`.
   - Start / confirm gateway: port `8642` LISTENING (record PID).
   - Tail `Media\hermes-gateway.log` for MCP load lines mentioning `computer_use` /
     `computer-use-mcp` (startup registration).
5. **End-to-end tool smoke (only if a live session is available)**
   - With the app running as **primary persona** and `PrimaryLLM=hermes`, send a benign action
     request (e.g. "take a screenshot and tell me the active window title") and confirm from
     `hermes-gateway.log` that a `computer_use` tool call fired. If no desktop session, mark
     **N/A — headless/no-UI cycle** with reason.

## Pass / Fail (report must state each)

| Check | Pass criteria |
|---|---|
| Hermes present | `hermes --version` succeeds |
| Config location | `hermes config path` resolves; file dumped; single authoritative dir identified |
| computer_use registered | `mcp_servers.computer_use enabled: true` in the active config |
| Env key location | API key `.env` in the dir the gateway reads; mismatch explicitly flagged if any |
| Node/npx | `node` ≥ 18 and `npx -y computer-use-mcp` launches without error |
| Gateway up | `:8642` LISTENING (PID recorded); log shows MCP registration |
| Tool fire (optional) | `computer_use` call visible in log, OR `N/A` with reason |
